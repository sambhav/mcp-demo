# Runbook

For the service or alert in ARGUMENTS, write:

1. **What this alert means** and its user impact.
2. **First checks**: dashboards, logs and commands, each copy-pasteable.
3. **Mitigations**: ordered from safest to most invasive, with how to verify each worked.
4. **Escalation**: when and to whom.
5. **Background**: architecture notes needed to reason about the failure.
